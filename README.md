# 💫 About Me:
### Hi there! I'm Abhijeet 👋

**Python Full Stack Developer | AI & Machine Learning Enthusiast**

I am an Electronics & Telecommunication Engineering graduate from Pune, currently interning as a Python Full Stack Developer at Linkcode Technologies. I specialize in building end-to-end applications with a strong focus on Artificial Intelligence, RAG architectures, and fine-tuning Large Language Models (LLMs).

<br>

🚀 **I’m currently working on**
**AI-Powered Recruitment Automation:** Developing a fine-tuned model that automates the hiring lifecycle on platforms like Naukri. The system acts as a dual-agent: applying for jobs on behalf of candidates and auto-sourcing applicants for HRs based on resume-job description matching.

👯 **I’m looking to collaborate on**
Fine-tuning LLMs for specific domain tasks, web automation scripts (for job portals), and full-stack integration.

🌱 **I’m currently learning**
Advanced model fine-tuning techniques and scalable deployment for AI agents.

💬 **Ask me about**
Building RAG systems (like my project RAGCraft), Python backend development, IoT integrations (like my Raspberry Pi traffic controller), and automating workflows.
